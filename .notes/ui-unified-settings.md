# Einheitliche UI Controls, Design und Settings

Die App verwendet den m.git UI-X-Standard:

- Schrift: OpenDyslexic, NotoSans, CourierPrime, Ubuntu, Ubuntu Mono
- Textskalierung: 50-160 %
- Hell/Dunkel sowie AMOLED-Stealth-Modus
- Akzentfarbe und Highlight-Farbe aus der gemeinsamen m.git-Farbpalette
- AppBar-Einstieg für Settings

Die fachliche Oberfläche ergänzt das gemeinsame Theme um das 2x3-Emotionsraster und den Stealth-Modus. Der Stealth-Modus ist eine visuelle Abdunklung, kein Schutz gegen Screenshots oder Systemzugriff.
