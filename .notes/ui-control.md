# UI Controls: filterlos.ich

- Home: festes 2x3 Raster, ganze Kachel öffnet direkt den passenden Capture-Composer.
- Capture: Textfeld, Bild wählen, Audio aufnehmen/stoppen, Android-On-Device-Diktat, verschlüsselt sichern.
- Timeline: vor Anzeige PIN-Gate; optional Android-Biometrie; Filterchips für alle sechs Kategorien.
- Timeline-Einträge: chronologisch, Anhänge anzeigen/abspielen, Löschen mit Bestätigung.
- Settings: globale UI-X-Controls, Stealth-Modus, Emoji-Tasten, Timeline-PIN und optionale Biometrie.
- Icon-only Controls besitzen Tooltips; Speichern/Löschen zeigen kurze Statusmeldung oder Bestätigung.
